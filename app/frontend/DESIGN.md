# DESIGN.md — Atoms 风格 AI 应用生成平台官网 Demo

## Direction & Layout

产品定位：面向开发者与创业者的 AI 应用生成平台官网 + 产品演示页。用户在首屏就能输入一句需求，实时看到"提示词 → 生成中 → 可运行应用"的过程。

- 情绪：冷静、精密、带工程感的夜间实验室氛围；像一台正在运算的机器，而不是营销彩页。
- 第一视觉信号：全屏近黑背景上的一个巨大的「需求输入台」（Prompt Console），输入框自带打字机占位提示与一个发光的运行按钮。
- 定义性视觉概念：**原子网格（Atom Grid）**——背景是 1px 细网格 + 缓慢漂移的粒子轨道，暗示"原子聚合成应用"。视觉参考：Linear 与 Vercel 的暗色工程美学（仅凭公开印象，未实际打开页面）。
- 应该：精密、克制、高信息密度、有真实产品截图感。不应该：蓝紫渐变 SaaS 模板、玻璃拟态泛滥、居中卡片堆叠。

布局：
- 最大内容宽度 1200px，两侧 padding 24px（移动端 16px）。
- 首屏为非对称 62/38：左侧文案 + Prompt Console，右侧是生成结果的实时预览窗（带假的浏览器标题栏）。
- 区块纵向间距：桌面 112px，移动 64px。卡片间距 20px。
- 模板画廊为 12 栏网格中的 3 列（平板 2 列、移动 1 列）。
- 断点：<768px 单列，hero 上下堆叠，预览窗在文案下方；768–1023px 两列网格；≥1024px 完整非对称布局。图片比例桌面 16:10，移动 4:3。

Do / Don't：
- Do：保留网格背景、等宽字体标记（prompt、代码、状态），状态色只用于生成步骤指示。
- Don't：不要使用蓝紫渐变按钮、不要 Orbitron/Rajdhani 类科技字体、不要给卡片加发光外描边。
- Don't：不要用居中三列图标堆作为唯一内容结构。

## Tokens

颜色（暗色为唯一主题）：
- 背景 `#0B0C0E`；次级表面 `#141619`；卡片 `#17191D`；边框 `#24272D`。
- 主色（酸性青柠）`#C8F751`，用于主按钮、运行状态、关键强调，占比 ≤10%。
- 主色按下 `#B4E23C`；主色柔光 `rgba(200,247,81,0.12)`。
- 文本：主 `#F2F4F5`，次 `#A0A6AF`，弱 `#6B727C`。
- 状态：成功 `#4ADE80`，进行中 `#C8F751`，警告 `#FBBF24`，错误 `#F87171`。
- 强调辅色（仅用于图表/标签区分）：`#7DD3FC`、`#F0ABFC`。

字体（Google Fonts 可免费加载）：
- 标题/正文：`Space Grotesk`（几何但终端切角特别，工程感强），fallback `system-ui, sans-serif`。
- 等宽：`JetBrains Mono`，用于 prompt、代码、状态标签、数字。
- H1 56/60px，700，字距 -0.02em（移动 36/40px）；H2 32/38px，700；H3 20/28px，600；正文 16/26px，400；小字 13/20px，500；按钮 15px/600；等宽标签 12px/500，字距 0.06em 大写。

间距与形状：
- 间距阶：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 112。
- 圆角：按钮 10px，卡片 14px，输入框 12px，图片 12px，标签 6px；图标按钮为 8px 圆角方形（非圆形）。

深度：
- 主要靠 1px `#24272D` 边框 + 表面色差分层，不用大阴影。
- 浮层/下拉：`0 12px 32px rgba(0,0,0,0.5)` + 边框。
- 粘性顶栏：背景 `rgba(11,12,14,0.72)` + `backdrop-blur(12px)` + 底部 1px 边框。

## Shared Patterns & States

- `SectionHeading`：等宽大写小标签 + H2 + 次级描述，左对齐。
- `PromptConsole`：输入区 + 示例提示胶囊 + 主按钮。状态：idle / generating（按钮显示脉冲点与"生成中"）/ done。空输入时主按钮 disabled（不透明度 0.45，禁用指针）。
- `BuildTimeline`：生成步骤列表，每步有 pending（灰点）/ running（青柠点 + 脉冲）/ done（✓ 成功色）三态。
- `PreviewWindow`：带三点标题栏的预览容器，内部渲染生成出的迷你应用（真实 React 结构，非图片）。
- `TemplateCard`：缩略图 + 名称 + 标签 + hover 时边框转主色、缩略图轻微放大 1.02。点击后进入对应模板的占位详情。
- `Button`：primary（主色底 + `#0B0C0E` 文字）、ghost（透明底 + `#A0A6AF` 文字 + 边框，hover 文字转主文本色，保持 `!bg-transparent`）。
- 空状态：模板筛选无结果时显示等宽提示文案 + 重置按钮。
- 占位状态：未完成的次级页面显示统一的"功能建设中"面板（图标 + 说明 + 返回首页）。

动效：
- 时长 180–260ms，缓动 `cubic-bezier(0.2,0.7,0.2,1)`；hover 位移不超过 2px。
- 生成流程用定时推进的步骤动画（非 IntersectionObserver），首屏内容初始即可见，不依赖滚动显示。
- 粒子/网格背景使用低速 CSS 动画，`prefers-reduced-motion` 时停用。

可访问性：
- 点击目标 ≥40px 高；正文对比度 ≥4.5:1；焦点环 `0 0 0 2px #0B0C0E, 0 0 0 4px #C8F751`。
- 图标按钮必须有 `aria-label`；输入框有可见 label 或 `aria-label`；键盘可完成"输入 → 生成"全流程。

## Media

本页是产品演示型落地页，核心视觉是"可运行的界面"而非摄影图。
- 首屏预览窗内部用**真实 DOM 渲染的迷你应用**（仪表盘 / 落地页 / 待办三种），不使用截图图片，保证真实感与可交互。
- 模板画廊缩略图使用 CSS 构成的抽象界面线框（色块 + 线条），明确允许用 SVG/色块替代真实图片，避免无意义的 AI 生成图。
- 背景允许使用细网格 + 径向柔光（主色 12% 透明度），不使用蓝紫渐变。
- 不做全出血摄影图；不在图像上叠加长段文字。
