# Changelog — 平台发布记录

> 本文档与前端页面 `/changelog` 同源：数据源为 `app/frontend/src/data/changelog.ts`，页面组件为 `app/frontend/src/pages/Changelog.tsx`。
> 新增版本时在数据源数组顶部追加一条 `Release`，页面会自动置顶并标记 `LATEST`，类型筛选计数与版本锚点跳转同步更新。

## 这份记录是什么

这是**平台自身**的发布记录，记录 Atoms 风格 AI 应用生成平台的版本迭代与能力升级。

它与**用户生成项目的版本历史**是两个不同的对象：用户每个生成项目自己的版本链保存在 `project_versions` 表，通过 `GET /api/v1/generation/projects/{id}/versions` 查询，并在项目详情页展示（见 `docs/backend.md`）。请不要把两者混为一谈。

## 记录结构

| 字段 | 含义 |
|------|------|
| `version` | 版本号，同时作为页面锚点，例如 `/changelog#v0.6.0` |
| `date` | ISO 日期，直接用于展示与 `<time dateTime>` |
| `title` | 该版本的主题 |
| `summary` | 一句话说明这一版解决了什么 |
| `tags` | 主题标签，页面以 `#tag` 形式呈现 |
| `items` | 变更条目，类型取值为 `feature`（新增）/ `improve`（优化）/ `fix`（修复） |

当前共 8 个版本、43 条变更条目，最新版本为 `v0.8.0`（2026-09-23）。

## v0.8.0 · 2026-09-23

**真实生成与可访问产物**

生成链路换成真实实现：六个阶段由真实模型驱动，产物托管对象存储并以 iframe 预览，执行改为后台异步且失败自动退还额度。

标签：`#ai` `#storage` `#reliability`

- **新增** 六个阶段全部改由真实模型驱动：需求解析、方案规划与代码编写均调用真实模型，产出可运行的完整应用。
- **新增** 生成产物上传对象存储并通过 iframe 预览真实可访问地址，不再用组件模拟生成结果。
- **新增** 创建接口改为后台异步执行：请求只做校验、占用额度与落库并立即返回，阶段由服务端后台工作器推进。
- **优化** 配额改为条件原子扣减，模型失败自动退还额度，重试开启新一批任务且不重复扣额。
- **优化** 慢调用前后不再持有数据库事务，阶段执行拆为「短事务抢占 → 无连接慢调用 → 短事务回写」三段。
- **优化** 阶段具备原子抢占与 600 秒陈旧回收，进程重启后自动接管未完成项目，多端轮询不会重复执行同一阶段。
- **优化** 结构化输出增加本地容错与截断补全，减少因模型输出小瑕疵而中断整条生成链。
- **优化** 预览地址按对象键即时解析、不落库，避免签名链接过期后失效。
- **修复** 修复生成过程中并发轮询与后台阶段争抢数据库连接导致的网关 502。
- **修复** 修复平台登出回跳缺少路由导致停留在空白页的问题，新增登出完成页并统一返回首页。

## v0.7.0 · 2026-09-23

**账号体系与项目持久化**

接入平台统一账号：注册、登录与退出串成一条完整链路，生成的项目按账号归属并可在「我的项目」中回看。

标签：`#auth` `#projects`

- **新增** 新增账号入口：未登录点击「免费开始」先进入注册页，由平台账号页完成注册或登录。
- **新增** 新增「我的项目」列表与项目详情页，展示六阶段流水线、生成方案、测试报告与版本记录。
- **新增** 新增按账号隔离的额度视图，每周期免费额度用尽时给出明确提示而非静默失败。
- **优化** 顶栏统一为账号区：未登录显示「登录 / 免费开始」，已登录显示账号邮箱与「退出登录」，桌面端与移动端一致。
- **优化** 登录后可回到首页需求输入区并自动聚焦，无需重新寻找入口。
- **修复** 修复已登录时首页页脚仍显示「登录」入口的问题，该入口与账号状态无关，已移除。
- **修复** 修复退出登录返回 500、登录态已清除却停留在原页面的问题；退出接口支持 GET/POST 并可在平台侧异常时降级。

## v0.6.0 · 2026-09-22

**生成流水线对齐六阶段**

把「测试验证」补进主流程，生成过程由五步变为六步，每一步的产出都可追溯。

标签：`#pipeline` `#testing`

- **新增** 新增「测试验证」阶段：单元用例、冒烟用例与语句覆盖率随应用一起产出。
- **新增** 生成完成后展示测试报告面板，失败用例会被回灌到代码生成阶段重试一次。
- **优化** 时间线支持 pending / running / done 三态与脉冲动画，长任务等待过程不再空白。
- **优化** 尚未落地的次级页面统一为「建设中」说明页，不再出现点不动的假界面。
- **修复** 修复生成过程中刷新页面后时间线停在 running 状态的问题。

## 维护约定

1. 新版本追加在 `app/frontend/src/data/changelog.ts` 数组的**最前面**，保持版本倒序。
2. 本文件同步追加对应章节，保持与数据源逐条一致（版本号、日期、标题、摘要、标签、条目与类型）。
3. 条目类型只使用 `feature` / `improve` / `fix` 三种，页面据此渲染「新增 / 优化 / 修复」标签与筛选计数。
4. 发布记录只描述已真实落地的能力，不写入计划中的功能。
