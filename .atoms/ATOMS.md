# Project Context

## Project Overview

Atoms 风格 AI 应用生成平台的官网 + 产品演示页。用户用一句自然语言描述需求，页面展示「需求输入 → 六阶段生成流水线 → 可运行应用预览」的完整链路。阶段一交付纯前端演示版；阶段二已接入 Atoms Cloud：账号复用平台认证，项目/任务/版本/配额持久化，首页生成链路改为创建任务并轮询服务端阶段状态，登录用户可查看自己的项目列表。

| 2026-09-22 | 「免费开始」用 sessionStorage 意图 + 全局兜底消费实现登录后回跳聚焦 | Alex | 登录落点由平台 `/auth/callback` 控制，应用无法指定回跳地址 |
| 2026-09-22 | 未登录「免费开始」指向产品侧 `/signup` 注册页，由该页调起平台账号页完成注册 | Alex | Web SDK 仅提供 `me/toLogin/login/logout` 四个认证方法，注册与登录共用平台账号页，因此用独立注册入口承接「注册」语义 |

| 2026-09-23 | 阶段三预览窗由组件渲染改为 iframe，加载对象存储产物的真实可达地址 | Alex | 生成结果已是真实可运行应用，iframe 才能如实呈现，避免用本地组件冒充生成产物 |
| 2026-09-23 | 产物地址不入库，只保存对象键 `artifact_key`，预览地址每次即时解析 | Alex | 签名地址有有效期，持久化会在过期后产生失效链接 |
| 2026-09-23 | 配额扣减改为条件原子更新，模型失败时退款 | Alex | 并发首次创建不超扣，模型不可用时不白扣用户额度 |
| 2026-09-23 | AI 与对象存储调用前后拆分数据库事务，阶段用原子抢占 + `600` 秒陈旧回收 | Alex | 避免长事务占用连接池，且多端轮询不会重复执行同一阶段 |
| 2026-09-23 | 登出回跳补上 `/logout-callback` 路由，替代原先无路由的空白落点 | Alex | 平台登出会跳回该地址，缺少路由会让用户登出后停在空白页 |
| 2026-09-23 | 结构化输出解析加本地容错（尾随逗号清理 + 截断括号/字符串补全），模型修复调用作为兜底 | Alex | 模型偶发截断或尾随逗号时，不必再花一次调用，也不会因小瑕疵中断整条生成链 |
| 2026-09-23 | 模型调用失败时退还配额并保证不落半成品项目 | Alex | 外部额度或服务异常属于平台侧问题，不应由用户承担额度损失，也不该产生不可用的项目记录 |
| 2026-09-23 | 阶段执行拆为「短事务抢占 → 无连接慢调用 → 短事务回写」三段 | Alex | 整段慢调用持有连接会与并发轮询争夺连接池，在无服务器小池下直接表现为池超时并放大为网关 502 |
| 2026-09-23 | 无服务器连接池由 `1/0` 放宽为 `5/5`（可用环境变量覆盖） | Alex | 单连接会让后台阶段与浏览器轮询互相阻塞，5 秒获取超时即抛 `QueuePool limit` 并返回 5xx |
| 2026-09-23 | 请求在等待后台工作器前先归还数据库连接，快照用独立短会话重读 | Alex | 请求持有连接等待工作器时，工作器自身也需连接，形成自锁式争抢；短会话重读同时保证响应是最新状态 |

## Constraints

- 视觉规范以 `app/frontend/DESIGN.md` 为准：暗色为唯一主题、主色 `#C8F751` 占比 ≤10%、不使用蓝紫渐变。
- 更新日志为平台自身的发布记录（`/changelog`），与用户生成项目的变更追溯是两个不同对象，后者未落地。
- 产品边界以 `docs/mission.md` 为准：不做通用代码补全、不做拖拽搭建器、不做假界面。
- 前端固定为 shadcn/ui + Vite 技术栈；后端后续使用 Atoms Cloud，不自建第二套认证。
- 阶段二实际改动面为：生成链路（`run()` + 轮询）、账号状态、项目列表与详情页、导航新增「我的项目」；首页既有区块与布局结构未被改动。
- 构建策略：开发任务收尾时运行 `pnpm run lint && pnpm run build` 作为验证；纯文档或问答轮次不做构建。
- 交付策略：收到明确的开发或文档更新指令后动手；未获指令时只回答与分析，不主动重构。
