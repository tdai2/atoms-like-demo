# Project Summary

This project is a polished Atoms-style product demo for an AI application-generation platform. Users describe an application in natural language or select a preset, watch a simulated generation workflow, and preview a rendered mini-application such as a dashboard, coffee subscription page, or team task manager.

The frontend demonstrates the journey from an idea to a living application. It includes the landing page, generator simulation, mini-application previews, templates, pricing, navigation, blog pages, and responsive design. Authentication, billing, documentation, backend generation, persistent task state, storage, and publishing remain placeholders or planned integrations.

Product direction and implementation architecture are documented in `docs/mission.md` and `docs/plan.md`. The root `README.md` provides project-level documentation.

# Project Module Description

- **Landing page**: Presents the product value proposition, prompt input, preset prompts, generation controls, capabilities, templates, and pricing.
- **Application generator demo**: Accepts a request, runs a five-step simulated build timeline, and transitions the preview from building to live.
- **Mini application preview**: Renders dashboard, coffee subscription, and team task manager variants with reusable UI components.
- **Template library**: Displays templates filterable by Data, Marketing, Tools, and Commerce.
- **Site navigation**: Links to product sections, templates, documentation, login, and pricing.
- **Placeholder pages**: Represents unfinished documentation, authentication, billing, and template-detail destinations.
- **Blog**: Provides Markdown-based blog index and article pages with prerendered routes.
- **Responsive design system**: Uses a dark engineering aesthetic, atomic-grid visuals, cyan/lime accents, and mobile layouts.
- **Product documentation**: `docs/mission.md` defines the mission and roadmap; `docs/plan.md` documents the intended architecture and delivery plan.
- **Planned production architecture**: Separates the React experience layer, Edge Function interface layer, account/data services, AI gateway, and object storage.

# Usage

Install dependencies and start development:

```bash
cd app/frontend
pnpm install
pnpm run dev
```

Run validation and create a production build:

```bash
pnpm run lint
pnpm run build
```

The production output is generated by the Vite build configuration. Blog prerendering and sitemap generation are handled by scripts in `prerender/` when their corresponding package scripts are invoked.
