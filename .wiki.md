# Project Summary

This project is an Atoms-style product demo for an AI application-generation platform. Users submit natural-language app requests or select presets, follow a transparent six-stage generation workflow, and preview local mini-applications such as dashboards, coffee subscription pages, and team task managers.

The platform supports account authentication, user-scoped project persistence, generation tasks, versions, and PostgreSQL-backed quotas through Atoms Cloud. Authenticated users can create, monitor, retry, inspect, and delete their projects.

The frontend includes the landing generator, authentication flows, account-aware navigation, project list and detail views, templates, pricing, changelog, blog pages, responsive navigation, and local React previews. The changelog now includes a v0.7.0 release entry covering account access, project persistence, account navigation, quota views, and logout fixes.

Real model execution, external deployment URLs, billing, object-storage publishing, conversational editing, GitHub synchronization, and real test execution remain future work.

# Project Module Description

- **Landing and generator**: Accepts prompts and presets, creates persisted generation projects, polls progress, displays quota errors, and renders local previews.
- **Authentication-aware navigation**: Shows login and free-start actions for anonymous users and account email/logout controls for authenticated users.
- **Logout handling**: Supports resilient platform logout, local state cleanup, and homepage redirection after failures.
- **Signup and Start Free flow**: Preserves anonymous intent, routes users through signup and authentication, and focuses the generator after login.
- **Generation pipeline**: Advances through requirements parsing, solution generation, code writing, build validation, test validation, and preview publishing.
- **Project management**: Lists user projects, displays quota usage, supports deletion, and provides loading, empty, anonymous, and retryable error states.
- **Project detail**: Shows pipeline status, solution specification, test reports, version history, and retry actions.
- **Quota management**: Provides 20 Starter generations per natural month, resets monthly, deducts one generation per attempt, and excludes retries from additional usage.
- **Backend orchestration**: Coordinates project creation, task transitions, version records, quota checks, failures, and retries.
- **Entity persistence**: Stores user-scoped projects, build tasks, project versions, and usage quotas.
- **Mini-app previews**: Selects dashboard, coffee subscription, or team task manager variants using request keywords.
- **Template library**: Supports filtering for Data, Marketing, Tools, and Commerce.
- **Changelog and blog**: Provides release filtering, version navigation, static content, Markdown articles, prerendering, and sitemap generation.
- **Navigation and pricing**: Provides responsive navigation, account actions, Start Free CTAs, pricing tiers, and billing placeholders.
- **Supporting routes**: Includes sign-in, signup, authentication callback/error handling, logout callback, settings, protected admin routing, and under-construction pages.

# File Description Inventory

- **Workspace documentation**: `README.md`, `.atoms/`, `.wiki.md`, `docs/mission.md`, and `docs/plan.md`.
- **Backend authentication**: `app/backend/routers/auth.py` handles resilient GET/POST logout behavior and safe fallback handling.
- **Backend generation**: `app/backend/routers/generation.py` and `app/backend/services/generation.py` manage workflows, quotas, versions, failures, and retries.
- **Backend persistence**: `models/`, `data_models/`, and Alembic migrations define project, task, version, quota, and account records.
- **Frontend shell**: `src/App.tsx` and `src/main.tsx` define routing and application initialization.
- **Homepage**: `src/pages/Index.tsx` renders the generator and avoids duplicate footer login actions.
- **Authentication state**: `src/hooks/useAuthStatus.ts` and `src/contexts/AuthContext.tsx` expose account state and logout behavior.
- **Authentication pages**: Sign-in, signup, callback, error, and logout callback pages implement account flows.
- **Navigation**: `src/components/SiteHeader.tsx` renders account-aware responsive navigation.
- **Start Free flow**: `src/lib/startFree.ts`, `src/hooks/useStartFree.ts`, and `src/components/StartFreeIntentWatcher.tsx` preserve intent across authentication.
- **Project frontend**: `src/pages/Projects.tsx`, `src/pages/ProjectDetail.tsx`, `src/hooks/useProjects.ts`, and `src/lib/projects.ts` implement project queries, polling, retry, deletion, and detail views.
- **Changelog**: `src/data/changelog.ts` stores release entries, including the v0.7.0 account and project persistence release.
- **Product content**: `src/data/`, `src/components/MiniApp.tsx`, template pages, pricing pages, and shared UI primitives.
- **Blog and SEO**: `src/components/blog/`, `src/lib/blog.ts`, `prerender/`, `index.html`, and `public/robots.txt`.
- **Tooling and diagnostics**: Package manifests, lockfiles, Vite, TypeScript, ESLint, Tailwind, PostCSS, and `app/backend/logs/app_20260923.log`.

# Usage

Install frontend dependencies and start development:

```bash
cd app/frontend
pnpm install
pnpm run dev
```

Run frontend checks and build:

```bash
pnpm run lint
pnpm run build
```

Install backend dependencies:

```bash
cd app/backend
python -m pip install -r requirements.txt
```

Apply database migrations when backend environment configuration is available:

```bash
alembic upgrade head
```

Run the backend using the configured FastAPI entry point or startup helper:

```bash
cd app
./start_app_v2.sh
```

For release verification, confirm that the changelog displays v0.7.0 as the newest release, marks it as latest, updates filtering and version navigation, and renders the new entry correctly. Also verify authentication-aware navigation, logout recovery, project generation, quotas, saved projects, project details, previews, and changelog content.
