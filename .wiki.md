# Project Summary

This project is a polished Atoms-style product demo for an AI application-generation platform. Users describe an application in natural language or select a preset, observe a transparent six-stage simulated generation workflow, and preview a rendered mini-application such as a dashboard, coffee subscription page, or team task manager.

The frontend demonstrates the journey from idea to tested, previewable application through landing, generation, validation, preview, templates, pricing, navigation, and blog experiences. Authentication, billing, backend generation, persistence, storage, publishing, and continuous GitHub synchronization remain unimplemented. Atoms workspaces and GitHub repositories are separate; code must be exported and manually committed to GitHub.

# Project Module Description

- **Landing page**: Presents the product value proposition, natural-language prompt input, preset prompts, generation controls, capabilities, templates, pricing, CTA, and footer.
- **Application generator demo**: Accepts a request and runs a six-stage simulated workflow: requirement analysis, solution generation, code writing, build validation, test validation, and preview publishing.
- **Generation timeline**: Displays pending, active, and completed states with animated progress and transparent workflow status.
- **Test validation report**: Shows visible post-generation results including 24/24 unit tests, 6/6 smoke tests, and 82% statement coverage.
- **Mini application preview**: Renders dashboard, coffee subscription, and team task manager variants with reusable React components and keyword-based selection.
- **Template library**: Displays templates filterable by Data, Marketing, Tools, and Commerce, including empty-state reset behavior.
- **Pricing and navigation**: Provides three pricing tiers, highlighted Pro plan, product navigation, and responsive layouts.
- **Placeholder pages**: Represents unfinished documentation, authentication, billing, changelog, and template-detail destinations without pretending to implement them.
- **Blog**: Provides Markdown-based blog index and article pages with prerendered routes.
- **Responsive design system**: Uses a dark engineering aesthetic, grid visuals, cyan/lime accents, equal-width status tags, focus states, and reduced-motion support.
- **Code export workflow**: Exported workspace files can be committed to a GitHub repository manually. Versions and Remix support workspace-side version exploration, but no built-in bidirectional GitHub sync exists.

# Usage

Install dependencies and start development:

```bash
cd app/frontend
pnpm install
pnpm run dev
```

Run linting and create a production build:

```bash
pnpm run lint
pnpm run build
```

The production output is generated by the Vite build configuration. Blog prerendering and sitemap generation are handled by scripts in `prerender/` when their corresponding package scripts are invoked.

The completed demo can be checked in App Viewer by entering a request such as “Build a team task collaboration app,” then observing the six-stage workflow, test report, and generated preview.
