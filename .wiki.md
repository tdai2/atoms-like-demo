# Project Summary

This project is an Atoms-style product demo for an AI application-generation platform. Users submit natural-language requests or presets, receive persisted multi-stage generation workflows, and preview generated applications from stored artifacts.

The platform provides authenticated, user-scoped projects with persisted solutions, tasks, versions, quotas, test results, bug reports, repair histories, and object-storage artifacts. Generation and bug repair run asynchronously through independently persisted stages and background workers.

Stage 5, **Bug Submission, Recording, and Automatic Repair**, is complete. Users can submit and manage bugs, trigger AI-assisted repairs, rerun linked test cases against repaired artifacts, inspect repair history, and clean up bug data with project deletion. End-to-end verification, backend compilation, frontend linting, and production builds pass. Real model-repair success-path testing remains limited by available AI balance.

# Project Module Description

- **Landing and generator**: Accepts prompts and presets, creates projects, polls progress, displays quota and gateway errors, and previews generated applications.
- **Asynchronous generation pipeline**: Executes persisted generation stages through short database transactions and independent worker sessions.
- **Pipeline runner**: Claims stages, prevents project-level duplicates, recovers after restarts, and reclaims stale stages.
- **Authentication and authorization**: Supports OIDC, PKCE, platform-token exchange, JWT verification, protected routes, logout callbacks, and user-scoped resources.
- **Project management**: Lists projects, shows quota and progress, supports retries and deletion, and handles loading, empty, anonymous, and error states.
- **Project detail**: Displays pipeline status, solutions, versions, artifact previews, testing, and bug-repair panels.
- **Artifact storage and preview**: Publishes generated applications to object storage, resolves preview locations dynamically, and supports object deletion for cleanup.
- **Quota management**: Provides Starter generation quotas, atomic deductions, duplicate-retry protection, refunds for failed model attempts, and explicit AI-balance errors.
- **Backend orchestration**: Coordinates ownership, stage transitions, AI calls, artifact publication, versions, failures, retries, quotas, testing, bug repair, and cleanup.
- **Test-case management**: Generates structured cases from persisted solutions and artifact source, validates limits, deduplicates cases, and preserves manual cases during regeneration.
- **Test execution**: Runs deterministic assertions against current artifact source, excludes disabled cases, persists aggregate statistics and per-case results, and supports execution history.
- **Bug management**: Creates, edits, closes, reopens, and deletes user-scoped bugs; validates artifact readiness and linked test cases.
- **Automatic bug repair**: Prevents concurrent repairs, records repair failures, rewrites artifact source through the AI service, publishes validated versions, advances project artifact pointers only on success, and reruns linked tests.
- **Repair history**: Persists repair attempts and outcomes, including model, storage, validation, and retest failures.
- **Bug Suite UI**: Provides bug submission, severity and test-case association, repair actions, close/reopen/delete controls, status counts, repair history, and loading, empty, unavailable-artifact, and error states.
- **Entity persistence**: Stores user-scoped projects, tasks, quotas, solutions, artifacts, versions, test cases, test runs, test results, bugs, and repair logs.
- **Reliability and diagnostics**: Handles timeouts, gateway errors, stale work, idempotent operations, connection-pool pressure, health checks, structured logs, telemetry controls, and truthful failure states.
- **Template library**: Supports Data, Marketing, Tools, and Commerce filtering.
- **Changelog and blog**: Provides release filtering, version navigation, Markdown content, prerendering, and sitemap generation.
- **Navigation and pricing**: Provides responsive navigation, account actions, Start Free CTAs, pricing tiers, and billing placeholders.
- **Supporting routes**: Includes sign-in, signup, authentication callbacks and errors, logout callback, settings, administration, and under-construction pages.
- **Roadmap planning**: Stage 4 testing and Stage 5 bug repair are complete. Future work covers conversational incremental editing with rollback, custom domains, and team collaboration.
- **Documentation**: Maintains product, architecture, planning, frontend, backend, changelog, progress, and verification documentation under `docs/` and `.atoms/`.

# Usage

Install frontend dependencies and start development:

```bash
cd app/frontend
pnpm install
pnpm run dev
```

Run frontend checks and production build:

```bash
pnpm run lint
pnpm run build
```

Install backend dependencies:

```bash
cd app/backend
python -m pip install -r requirements.txt
```

Configure the backend according to `docs/backend.md`, including database, authentication, AI, object-storage, connection-pool, and diagnostic settings.

Apply database migrations:

```bash
cd app/backend
alembic upgrade head
```

Run the application with the configured FastAPI entry point or startup helper:

```bash
cd app
./start_app_v2.sh
```

Production deployments should run without reload mode so background workers are not interrupted by development reloads.

Run backend verification:

```bash
cd app/backend
python verify_stage3.py
python verify_quota_refund.py
python verify_gateway_timeout.py
python verify_pipeline.py
python verify_test_suite.py
python verify_bug_fix.py
```

Complete AI-assisted generation or repair verification requires sufficient external AI balance and a project with a published artifact. When model balance is unavailable, repair verification skips the real model-success branch while still checking truthful failure handling, unchanged project pointers, cleanup, and deterministic retesting behavior.
