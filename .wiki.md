# Project Summary

This project is a polished Atoms-style product demo for an AI application-generation platform. Users describe an application in natural language or choose a preset, watch a simulated five-step generation timeline, and preview a rendered mini-application such as a dashboard, coffee subscription page, or team task manager.

The product mission is to help people move from an idea to a living, usable application rather than receiving disconnected code fragments. The mission document defines the product principles, target users, success signals, boundaries, and roadmap from the current demo toward a real generation loop.

The landing page also presents platform capabilities, filterable templates, pricing plans, documentation, authentication, billing, and template-detail entry points. Secondary areas currently use placeholder or “under construction” pages, while the primary generation experience is interactive and responsive.

# Project Module Description

- **Landing page**: Presents the product value proposition, request input, preset prompts, generation controls, capability highlights, template library, and pricing.
- **Application generator demo**: Accepts a request, progresses through a five-step build timeline, and switches the preview from building to live.
- **Mini application preview**: Renders functional-looking dashboard, coffee subscription, and team task application variants with reusable UI components.
- **Template library**: Displays templates filterable by Data, Marketing, Tools, and Commerce.
- **Site navigation**: Provides links to product sections, templates, documentation, login, and pricing.
- **Placeholder pages**: Handles unfinished documentation, authentication, billing, and template-detail destinations.
- **Blog**: Supports blog index and article pages using Markdown content and prerendered routes.
- **Mission documentation**: Records the product mission, six operating principles, target users, success metrics, non-goals, and three-stage roadmap.
- **Responsive design system**: Uses dark engineering aesthetics, atomic grid visuals, cyan/lime accents, and mobile layouts.

# Usage

Install dependencies and start development:

```bash
cd app/frontend
npm install
npm run dev
```

Run validation and create a production build:

```bash
npm run lint
npm run build
```

The production output is generated by the Vite build configuration. Blog prerendering and sitemap generation are handled by the scripts in `prerender/` when their corresponding package scripts are invoked.
