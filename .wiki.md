# Project Summary

This project is a polished Atoms-style product demo for an AI application-generation platform. Users describe an application in natural language or select a preset, observe a transparent six-stage simulated generation workflow, and preview a rendered mini-application such as a dashboard, coffee subscription page, or team task manager.

The implementation is a frontend-only demonstration using local static data. It includes the landing experience, simulated generation workflow, validation report, application previews, templates, pricing, blog routes, navigation, and placeholder pages. Backend generation, Atoms Cloud integration, authentication, billing, persistence, storage, publishing, and real GitHub synchronization are not connected. Workspace exports remain separate from GitHub repositories and must be committed manually.

Stage one is complete, and the latest documentation changes were reverted. No application source code or runtime behavior was changed.

# Project Module Description

- **Landing page**: Presents the product value proposition, prompt input, preset prompts, generation controls, capabilities, templates, pricing, calls to action, and footer.
- **Application generator demo**: Accepts a request and runs a six-stage simulated workflow covering requirements, solution generation, code writing, build validation, test validation, and preview publishing.
- **Generation timeline**: Displays pending, active, and completed workflow states with animated progress.
- **Test validation report**: Shows simulated results including 24/24 unit tests, 6/6 smoke tests, and 82% statement coverage.
- **Mini application preview**: Renders dashboard, coffee subscription, and team task manager variants with keyword-based selection.
- **Template library**: Supports filtering by Data, Marketing, Tools, and Commerce, including empty-state reset behavior.
- **Pricing and navigation**: Provides three pricing tiers, a highlighted Pro plan, responsive navigation, and product links.
- **Placeholder pages**: Marks unfinished documentation, authentication, billing, changelog, and template-detail destinations as under construction.
- **Blog**: Provides Markdown-based blog index and article pages with prerendered routes.
- **Authentication routes**: Includes callback and error-page placeholders without claiming a connected authentication service.
- **Responsive design system**: Uses a dark engineering aesthetic, grid visuals, cyan/lime accents, focus states, equal-width status tags, and reduced-motion support.
- **Delivery boundary**: Stage one covers the frontend demonstration. Atoms Cloud integration, accounts, project persistence, real generation, and version history remain planned for later stages.

# Usage

Install dependencies and start development:

```bash
cd app/frontend
pnpm install
pnpm run dev
```

Run linting and create a production build:

```bash
pnpm run lint
pnpm run build
```

The production output is generated by the Vite build configuration. Blog prerendering and sitemap generation are handled by scripts in `prerender/` when their corresponding package scripts are invoked.

To review the delivered experience, enter a request such as “Build a team task collaboration app” in the main prompt interface, then inspect the six-stage workflow, test report, and generated preview. The homepage and blog routes support prerender validation.
