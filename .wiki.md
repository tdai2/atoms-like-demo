# Project Summary

This project is a polished Atoms-style product demo for an AI application-generation platform. Users describe an application in natural language or choose a preset, watch a simulated generation workflow, and preview a rendered mini-application such as a dashboard, coffee subscription page, or team task manager.

The product demonstrates the path from an idea to a living application rather than disconnected code fragments. The current frontend delivers the interactive experience, while `mission.md` defines product direction and `plan.md` documents the intended architecture, modules, technology choices, data model, and implementation roadmap for production capabilities.

Implemented areas include the landing page, generator simulation, mini-application previews, templates, pricing, navigation, blog pages, and responsive design. Authentication, billing, documentation, template details, backend generation, persistent task state, data storage, and publishing remain placeholders or planned integrations.

# Project Module Description

- **Landing page**: Presents the product value proposition, prompt input, preset prompts, generation controls, capabilities, templates, and pricing.
- **Application generator demo**: Accepts a request, runs a five-step simulated build timeline, and transitions the preview from building to live.
- **Mini application preview**: Renders dashboard, coffee subscription, and team task manager variants with reusable UI components.
- **Template library**: Displays templates filterable by Data, Marketing, Tools, and Commerce.
- **Site navigation**: Links to product sections, templates, documentation, login, and pricing.
- **Placeholder pages**: Represents unfinished documentation, authentication, billing, and template-detail destinations.
- **Blog**: Provides Markdown-based blog index and article pages with prerendered routes.
- **Responsive design system**: Uses a dark engineering aesthetic, atomic-grid visuals, cyan/lime accents, and mobile layouts.
- **Project direction**: `mission.md` defines the product mission, principles, users, success measures, non-goals, and roadmap.
- **Implementation plan**: `plan.md` translates the mission into a layered architecture, frontend and backend modules, technology decisions, data model, generation state machine, and five-stage delivery plan.
- **Planned production architecture**: Separates the React experience layer, Edge Function interface layer, account/data services, AI gateway, and object storage. Persistent tasks and project version history are required for observable and iterative generation.

# Usage

Install dependencies and start development:

```bash
cd app/frontend
npm install
npm run dev
```

Run validation and create a production build:

```bash
npm run lint
npm run build
```

The production output is generated by the Vite build configuration. Blog prerendering and sitemap generation are handled by scripts in `prerender/` when their corresponding package scripts are invoked.
